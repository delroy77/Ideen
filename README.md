# Ideen

Dieses Repository ist der zentrale Sammelplatz für **neue Ideen, Konzepte und frühe Projektansätze**.

## Zweck

Nicht jede Idee benötigt sofort ein eigenes GitHub-Repository.

Neue Ideen werden deshalb zunächst hier gesammelt, strukturiert und bei Bedarf weiterentwickelt. So bleiben frühe Konzepte an einem zentralen Ort, ohne für jeden Ansatz direkt ein separates Repository anzulegen.

## Grundregel

> **Jede neue Idee kommt zuerst in dieses Repository.**

Bestehende Projekte und bereits vorhandene Repositories werden durch diese Regel **nicht verändert**.

## Struktur

Jede Idee erhält einen eigenen Unterordner:

```text
Ideen/
├── README.md
├── projekt-idee-a/
│   ├── README.md
│   └── ...
├── projekt-idee-b/
│   ├── README.md
│   └── ...
└── ...
```

Der jeweilige Ideenordner kann enthalten:

- eine eigene `README.md`
- Konzept und Zielsetzung
- Funktionsideen
- technische Überlegungen
- Mockups oder Diagramme
- erste Prototypen
- Notizen und offene Punkte

Es gibt bewusst **keine starre Mindeststruktur**. Der Umfang richtet sich nach dem Reifegrad der Idee.

## Vom Gedanken zum eigenen Projekt

Wenn sich zeigt, dass eine Idee ernsthaft weiterverfolgt wird und ein eigenständiges Projekt rechtfertigt, wird sie aus diesem Repository herausgelöst.

Der Ablauf ist:

```text
Neue Idee
    ↓
Ideen/<projektname>
    ↓
Konzept / erste Entwicklung / Bewertung
    ↓
Projekt ist tragfähig
    ↓
Neues GitHub-Repository anlegen
    ↓
Projekt aus Ideen in das neue Repository überführen
    ↓
Weiterentwicklung im eigenen Repository
```

Ab diesem Zeitpunkt wird das Projekt ausschließlich im neuen Repository weitergeführt.

## Status dieses Repositories

Dieses Repository enthält ausdrücklich auch:

- unfertige Ideen
- experimentelle Ansätze
- verworfene Konzepte
- frühe technische Tests
- Projekte ohne feste Roadmap

Inhalte hier sind daher **nicht automatisch produktionsreif oder aktiv in Entwicklung**.

---

**Prinzip:** Erst Idee sammeln. Dann bewerten. Erst bei echtem Projektpotenzial ein eigenes Repository erstellen.
