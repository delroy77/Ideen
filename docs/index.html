yt-automation

yt-automation ist ein privates Werkzeug, mit dem der Betreiber Videos auf seinen eigenen YouTube-Kanal hochlädt und deren Titel, Beschreibung, Kapitel und Thumbnails pflegt. Der Zugriff erfolgt über die YouTube Data API v3 und die Integrationsplattform Composio.

Die Anwendung wird nicht öffentlich angeboten und nur vom Betreiber selbst genutzt.
