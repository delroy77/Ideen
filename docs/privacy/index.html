Datenschutzerklärung – yt-automation

Stand: 26. November 2026 · English version below

1. Zweck

yt-automation ist ein privates Werkzeug des Betreibers, um Videos auf den eigenen YouTube-Kanal hochzuladen und deren Metadaten (Titel, Beschreibung, Tags, Kapitel, Thumbnails) zu verwalten. Es wird ausschließlich vom Betreiber selbst genutzt.

2. Welche Daten verarbeitet werden

Nach der Anmeldung mit einem Google-Konto erhält die Anwendung über die YouTube Data API v3 Zugriff auf den verknüpften YouTube-Kanal: Kanalinformationen, Videolisten und -statistiken sowie die Berechtigung, Videos hochzuladen und zu bearbeiten. Dazu werden OAuth-Zugriffstoken gespeichert.

3. Wo die Daten verarbeitet werden

Die Zugriffstoken und API-Aufrufe werden über die Integrationsplattform Composio abgewickelt. Es gelten zusätzlich die Datenschutzbestimmungen von Composio und von Google. Es gelten außerdem die Nutzungsbedingungen von YouTube.

4. Weitergabe

Daten werden nicht verkauft, nicht für Werbung genutzt und nicht an Dritte weitergegeben, außer an die oben genannten Dienste, soweit es für die Funktion technisch nötig ist. Die Nutzung von Daten, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

5. Speicherdauer und Widerruf

Daten werden nur so lange gespeichert, wie die Verbindung besteht. Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden; danach kann die Anwendung nicht mehr auf das Konto zugreifen.

Privacy Policy – yt-automation

yt-automation is a private tool used solely by its operator to upload videos to, and manage metadata on, the operator's own YouTube channel via the YouTube Data API v3. After signing in with Google, it accesses channel information, video lists and statistics, and the permission to upload and edit videos; OAuth tokens are stored for this purpose by the integration platform Composio. Data is not sold, not used for advertising and not shared with third parties beyond what is technically required to operate the tool. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using this tool you are also bound by the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.
