# Delroys Suite 0.1.0

Eigenständiges Add-on für WoW Forever. Diese Version enthält Fensterverwaltung,
Einrichtung und die Übersicht optionaler Integrationen.

## Installation

Unter **Actions → Delroys Suite → Build → Artifacts** das Build-Artefakt öffnen.
Die darin enthaltene `DelroysSuite_0.1.0.zip` entpacken. Beide Add-on-Ordner
direkt nach `_forever_/Interface/AddOns` kopieren und WoW vollständig neu starten.
Die Einrichtung einmal abschließen. Danach öffnet die Münze an der Minimap
oder `/dsuite` das Fenster. `/dsuite setup` öffnet die Einrichtung erneut.
Falls gleichzeitig 0.3.0 aktiv ist, öffnet `/delroysuite` eindeutig 0.1.0.

Die Titelleiste verschiebt das Fenster. Der Griff unten rechts ändert die Größe.
Position und Größe bleiben nach dem Neuladen erhalten.
Ein Klick auf Integrationen lädt das eigene Integrationsmodul bei Bedarf.
Die Suite erkennt AnoUI, TSM, Zygor, RestedXP, RareScanner und Questie.
Sie ändert deren Einstellungen nicht. Das Integrationsmodul bietet, soweit
verfügbar, einen Einstieg über den registrierten Befehl des jeweiligen Add-ons.
Farmen, Berufe, Karten und Dungeon-Journal folgen als eigene Module.
